# ✈️ AI Travel Planner

一個 AI 驅動的旅遊規劃應用程式，支援行程規劃、預算管理、旅行日記等功能。

## 部署到 GitHub Pages（3步驟）

### 步驟 1：建立 GitHub Repository
1. 前往 [github.com/new](https://github.com/new)
2. Repository name 輸入：`travel-app`
3. 選 **Public**
4. 點「Create repository」

### 步驟 2：上傳檔案
把這個資料夾的所有檔案上傳到 GitHub：
- 拖曳檔案到 GitHub 網頁
- 或使用 GitHub Desktop

### 步驟 3：開啟 GitHub Pages
1. 進入 Repository → Settings
2. 左側選「Pages」
3. Source 選「GitHub Actions」
4. 等待 2 分鐘，你的 app 就會在以下網址上線：

```
https://你的帳號.github.io/travel-app
```

## 手機安裝

### iPhone / iPad
1. 用 Safari 開啟網址
2. 點右下角「分享」按鈕
3. 選「加入主畫面」
4. 像 app 一樣從主畫面開啟

### Android
1. 用 Chrome 開啟網址
2. 點右上角三點選單
3. 選「加入主畫面」

## 功能
- 🏠 首頁：快速入口、功能介紹
- 🧭 探索：景點搜尋、分類篩選、加入行程
- 📅 行程：旅行時間軸、統計數據、AI 優化
- 💰 預算：花費追蹤、分類圖表、明細記錄
- ✈️ 旅行：多旅程管理、倒數計時、新增旅程
